## Dự đoán của tôi về thứ tự SQL Server thực sự xử lý SELECT … FROM … WHERE … GROUP BY … ORDER BY

1. From/Join : Chọn bảng dữ liệu
2. Where : Lọc dữ liệu theo điều kiện
3. Group By : Nhóm dữ liệu
4. Having: Lọc dữ liệu sau khi nhóm
5. Select : Chọn các cột cần lấy
6. Distinct : Loại bỏ trùng lặp
7. Order By : Sắp xếp kết quả
8. Limmit/ Off set : Giới hạn số dòng
